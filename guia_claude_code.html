Instala Node.js
Lo necesita Claude Code para funcionar · Gratis
⌄
1
Descarga Node.js desde nodejs.org
Entra en la web y descarga la versión LTS (la de la izquierda, marcada como "Recommended for most users").
nodejs.org/en/download

2
Instala el ejecutable
Abre el archivo descargado y sigue el instalador. Dale "Next" a todo. No cambies nada. Al final pulsa "Finish".
⚠️ Importante: cuando el instalador te pregunte si quieres instalar herramientas adicionales (chocolatey, etc.) en Windows, puedes dejarlo en blanco. No es necesario.
3
Verifica que se instaló bien
Abre la terminal (Mac: busca "Terminal" en Spotlight. Windows: busca "PowerShell") y escribe este comando:
TERMINAL
node --version
Si ves algo como v22.x.x es que está perfecto.
💡 Si el comando no funciona, cierra la terminal y ábrela de nuevo. A veces necesita reiniciarse para reconocer la instalación.

PASO 04
Instala Claude Code en la terminal
El comando que lo activa todo · 1 minuto
⌄
1
Abre la terminal integrada de VS Code
Dentro de VS Code ve al menú superior: Terminal → New Terminal. Aparecerá una ventana negra en la parte de abajo. Eso es la terminal.
⌨️ Atajo de teclado: Ctrl + ` en Windows o Cmd + ` en Mac.
2
Instala Claude Code con npm
Copia y pega este comando en la terminal y pulsa Enter. Tardará unos segundos en instalarse.
🍎 Mac
🪟 Windows
MAC — TERMINAL
npm install -g @anthropic-ai/claude-code
WINDOWS — POWERSHELL (como Administrador)
npm install -g @anthropic-ai/claude-code
⚠️ Windows: si te da error de permisos, abre PowerShell como Administrador (clic derecho → "Ejecutar como administrador") y vuelve a ejecutar el comando.
3
Verifica la instalación
Escribe este comando para comprobar que todo está bien:
MAC / WINDOWS
claude --version
Si te muestra un número de versión, está perfecto.
⚠️ Windows — error "no se reconoce el comando": cierra PowerShell, ábrelo de nuevo y vuelve a intentarlo. Si sigue fallando, ejecuta npx @anthropic-ai/claude-code --version como alternativa.
4
Autentícate con tu cuenta
La primera vez que ejecutes Claude Code te pedirá que entres con tu cuenta. Ejecuta:
TERMINAL
claude
Se abrirá el navegador para autenticarte. Entra con tu cuenta Pro y listo.
PASO 05
Crea tu primer proyecto
La carpeta donde va a vivir tu agente de ventas
⌄
1
Crea una carpeta en tu escritorio
🍎 Mac
🪟 Windows
Abre la terminal de VS Code y escribe:
MAC — TERMINAL
mkdir ~/Desktop/sistema-agentico
cd ~/Desktop/sistema-agentico
Abre la terminal de VS Code y escribe:
WINDOWS — POWERSHELL
mkdir $HOME\Desktop\sistema-agentico
cd $HOME\Desktop\sistema-agentico
💡 También puedes crear la carpeta manualmente en el escritorio y luego abrirla desde VS Code con File → Open Folder.
2
Abre la carpeta en VS Code
Ve a File → Open Folder y selecciona la carpeta sistema-agentico que acabas de crear. Ahora VS Code está apuntando a esa carpeta.
3
Crea la estructura de carpetas del sistema
Esta es la arquitectura del sistema completo. Cada carpeta es un agente o bloque. Pega este comando en la terminal:
🍎 Mac
🪟 Windows
MAC — TERMINAL
mkdir -p ventas prospeccion contenido analisis dashboard docs
WINDOWS — POWERSHELL
mkdir ventas, prospeccion, contenido, analisis, dashboard, docs
📁 sistema-agentico/
📁 ventas/ ← empezamos aquí
📁 prospeccion/
📁 contenido/
📁 analisis/
📁 dashboard/
📁 docs/
ℹ️ Solo vas a usar ventas/ este fin de semana. El resto de carpetas ya están preparadas para cuando llegues a esos bloques.
