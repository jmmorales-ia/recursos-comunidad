Paso 01 · Visión general

Qué vas a construir

Antes de tocar código, necesitas entender la arquitectura completa. Este sistema tiene tres capas que trabajan juntas.

1
Research automático
El sistema monitoriza YouTube, Reddit y Google Trends cada día. Claude analiza esas fuentes y genera 6-8 ideas adaptadas a tu avatar y posicionamiento.
2
Tú decides en Telegram
Recibes un menú con las ideas. Eliges con los números. El sistema genera el contenido completo para los formatos que selecciones.
3
Assets y Notion
Al aprobar, se generan las imágenes automáticamente, los vídeos con HeyGen si los necesitas, y todo queda organizado en Notion por formato.
⚡
La interfaz completa es Telegram. Notion es solo la vista de gestión. No necesitas abrir ningún panel para operar el sistema día a día.
La arquitectura en una línea
Flujo simplificado
// Fuentes → Research → Menú → Selección → Generación → Aprobación → Assets → Notion

Fuentes: YouTube RSS + Reddit + Google Trends
Cerebro: Claude Sonnet/Opus
Interfaz: Bot de Telegram
Imágenes: Freepik Magnific API
Vídeos: HeyGen API v2
Gestión: Notion (6 tablas)
Backend: FastAPI + Python en VPS

Paso 04 · Formatos

Los 6 formatos del sistema

Cada formato tiene su propio agente Claude con prompt especializado y su propia tabla en Notion.

💼
LinkedIn Posts
Post completo + brief visual para imagen de portada 1:1
📧
Email
Asunto + preview line + cuerpo con estructura Mira/historia/CTA/PD
🎠
Carrusel IG
7 slides con imágenes. Estilo dark (Hormozi) o tech light auto-detectado
▶️
YouTube
Guión completo + vídeo HeyGen multi-escena automático
📱
Script IG
Guión hablado 15-60s + instrucciones de edición + brief visual
🖼️
Miniatura YT
Brief visual + texto overlay (máx 5 palabras) + imagen 16:9
Cómo se generan las imágenes
🎨
Freepik Magnific API

Para LinkedIn y miniaturas de YouTube el prompt incluye siempre tu descripción física como referencia visual. Si subes fotos tuyas al bot con el caption "referencia presentador", el sistema las usa para mantener consistencia de cara en todas las imágenes generadas.

Estilo dark

Fondo negro, texto blanco, acentos naranja. Estilo Hormozi. Se auto-detecta para temas de ventas y negocio.

Estilo tech light

Fondo crema, circuitos, texto oscuro. Más educativo. Se auto-detecta para temas técnicos y de herramientas.

Paso 05 · Flujo operativo

Cómo funciona un día normal

Este es el ciclo completo desde que lanzas el research hasta que el contenido está en Notion aprobado.

1
Lanzas el research
Escribes /research en Telegram. El sistema investiga YouTube, Reddit y Google Trends en paralelo y genera 6-8 ideas con ángulo adaptado a tu negocio.
2
Recibes el menú
El bot te envía las ideas numeradas con su formato badge. Cada idea incluye título, ángulo y una línea de contexto.
3
Seleccionas las ideas
Respondes con los números: 1 3 para las ideas 1 y 3, o TODAS para generar todo.
4
El sistema genera el contenido
Recibes el draft completo de cada pieza en Telegram con preview. También crea la fila en Notion automáticamente.
5
Apruebas o editas
OK 1 para aprobar. EDITAR 1 linkedin [instrucciones] para reescribir con cambios. NO 1 para descartar.
6
Assets automáticos
Al aprobar LinkedIn se genera la imagen de portada. Al aprobar YouTube se genera el vídeo HeyGen. Todo queda en Notion con estado "publicar".

Paso 06 · Comandos

Todos los comandos del bot

Toda la interacción ocurre por Telegram. Aquí tienes el diccionario completo.

Research
Comandos de research
/research → ideas mixtas para todos los formatos
/research linkedin → solo para LinkedIn (alias: li)
/research email → solo para email (alias: mail)
/research youtube → solo para YouTube (alias: yt)
/research carousel → solo para carruseles (alias: car)
/research ig → solo para Stories/Reels (alias: reel, story)
Gestión de drafts
Selección y aprobación
1 3 → generar ideas 1 y 3
TODAS → generar todas las ideas
OK 1 → aprobar draft 1
OK 1 carrusel → aprobar + generar imágenes
OK 1 youtube → aprobar + generar vídeo HeyGen
EDITAR 1 linkedin [instrucciones] → reescribir con cambios
NO 1 → descartar (se archiva en Notion)
Drops — añadir tus propias ideas
Cómo dropear ideas al sistema
// Cualquier mensaje de más de 10 caracteres se guarda como idea
// Prefijo ! = prioritario (aparece sí o sí en el siguiente research)

"! Quiero crear contenido sobre el error más común de mi mercado"
"https://youtube.com/watch?v=xxx" ← referente para adaptar
[nota de voz] ← se transcribe con Whisper
[captura de carrusel] ← Claude Vision extrae la idea
Imágenes y vídeos manuales
