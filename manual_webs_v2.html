02 · Prompt maestro
Copia esto en Claude Code y empieza a construir
⌄
Este es el prompt completo para que Claude Code construya el sistema desde cero. Cópialo tal cual, pégalo en una sesión nueva y deja que trabaje.
// Prompt maestro — copia y pega en Claude Code
Quiero que construyas una aplicación web completa llamada "Constructor de Webs para Negocios Locales". El objetivo del sistema es este: Detectar negocios locales sin web o con web antigua, generar una web profesional para ellos en segundos usando IA y permitirme mostrársela como demo para cerrar la venta en el momento. Lo que necesito que construyas: 1. DETECCIÓN DE NEGOCIOS Una pantalla donde pueda introducir una zona (ciudad o barrio) y un sector (peluquería, fontanero, restaurante, clínica, etc.) y el sistema me devuelva una lista de negocios de esa zona que no tienen web o tienen una web muy básica o anticuada. Usa la API de Google Maps Places para buscarlos. Para cada negocio muestra: nombre, dirección, teléfono si está disponible, valoración y si tiene web o no. 2. GENERACIÓN DE WEB CON IA Para cada negocio de la lista, quiero poder hacer clic en "Generar web" y que el sistema cree automáticamente una web profesional completa usando Claude. La web generada debe incluir: - Diseño profesional adaptado al sector del negocio - Nombre y logo del negocio si lo tengo - Sección de servicios generada con IA según el sector - Imágenes reales del sector usando la API de Pexels - Chatbot de IA embebido que responde preguntas básicas del negocio - Botón de WhatsApp directo si tengo el teléfono - Formulario de contacto que envía los leads por Telegram - Diseño responsive que se vea bien en móvil 3. PREVIEW Y GESTIÓN Cada web generada debe tener un link de preview único que pueda abrir en el móvil para mostrárselo al cliente en directo. Cuando la web esté lista quiero recibir el link por Telegram automáticamente. Para cada prospecto quiero poder marcar el estado: pendiente, demo hecha, vendido, descartado. 4. PANEL DE CONTROL Una pantalla principal donde vea todos mis prospectos, su estado y las webs generadas. Que pueda buscar y filtrar por zona, sector y estado. APIs que necesito integrar: - Claude API (Anthropic) para generar el contenido de las webs - Google Maps Places API para detectar negocios - Pexels API para las imágenes - Telegram Bot API para recibir las notificaciones Stack recomendado: el que tú consideres más adecuado para que funcione bien y sea fácil de mantener. Que sea simple, no necesito nada complejo. Empieza por preguntarme las API keys que necesitas y luego construye el sistema paso a paso, explicándome qué hace cada parte en lenguaje simple.
⚡ Antes de pegar el prompt: ten preparadas tus API keys de Claude, Google Maps, Pexels y Telegram. Claude Code te las va a pedir al empezar. Si no las tienes todas, dile cuáles tienes y cuáles no y te guiará para conseguirlas.
💡 Si algo no funciona: dile a Claude Code exactamente qué pasa y qué ves en pantalla. Con esa información lo corrige solo. No necesitas saber programar para operar esto.

04 · Cierra la venta
El guión que funciona para presentar y cerrar
⌄
La demo hace el 80% del trabajo. Este guión es para el 20% restante.
Apertura — genera curiosidad sin vender
"Buenas, soy [nombre]. Me dedico a ayudar a negocios locales a conseguir más clientes con IA. ¿Tienes 2 minutos? Tengo algo que quiero enseñarte."
La demo — el momento que cierra solo
"Antes de venir he preparado algo para ti."

[Abres el preview en el móvil y se lo muestras]

"Es tu web. Con tu nombre, tu logo, tus servicios y un chat que responde a tus clientes solo, las 24 horas. La he generado en 30 segundos."
Cuando pregunten el precio
"Son [precio]. Pago único, sin mensualidades. Pero antes de hablar de precio, dime: ¿cuántos clientes nuevos consigues al mes ahora mismo buscándote en Google?"
Si dicen que lo tienen que pensar
"Entendido. Solo te digo una cosa: esta web ya está hecha. Si la quieres, la tienes hoy. Si no, la archivamos y listo. No hay presión ni hay propuesta que esperar."
Para cerrar
"¿Empezamos? Solo necesito que me confirmes el teléfono y el email donde quieres que lleguen los contactos del formulario."
Si ya tienen web pero es antigua
"Veo que tienes web, pero lleva tiempo sin actualizarse y no tiene botón de WhatsApp ni chat. Te genero una versión nueva en 30 segundos para que veas la diferencia."
⚠️ Regla de oro: nunca vendas antes de mostrar la demo. Genera primero, muestra después. La web ya hecha es tu mejor argumento. No hay propuesta ni presentación que la supere.

05 · FAQ
Preguntas que van a surgir
⌄
Las dudas más frecuentes cuando empiezas a construir y vender el sistema.
¿Necesito saber programar para construir esto?
No. Claude Code te guía paso a paso. Tú le describes lo que quieres, él construye, tú revisas. Si algo no funciona, le dices qué pasa y lo corrige. El prompt maestro ya tiene todo lo que Claude necesita saber para empezar.
¿Cuánto tiempo lleva construir el sistema?
Entre 2 y 4 horas de trabajo con Claude Code para tener una versión funcional. No es perfecto desde el principio, pero con eso ya puedes generar webs y hacer demos. El refinamiento viene después, con uso real.
¿Dónde se alojan las webs generadas?
En tu propio servidor o en servicios gratuitos como Railway o Render para empezar. Cuando tengas clientes pagando, mueves a un VPS que te da más control. Claude Code te ayuda con el despliegue también.
¿Puedo modificar la web después de generarla?
Sí. Puedes regenerarla con más información o editar el HTML directamente. Para ajustes rápidos, regenerar con mejor descripción suele ser suficiente y más rápido.
¿Y si el cliente quiere cambios después de comprar?
Eso es una oportunidad. Los cambios menores los haces en minutos regenerando. Para cambios grandes, tienes dos opciones: incluirlos en el precio original o cobrarlos aparte. Define esto antes de cerrar para evitar malentendidos.
¿Puedo montar un recurrente encima de esto?
Sí y es la parte más interesante. Una vez vendida la web, ofrece mantenimiento mensual: actualizaciones, cambios de contenido, mejoras del chatbot. 50-100€/mes por cliente es fácil de defender para un negocio que ya confía en ti. 10 clientes en recurrente son 500-1.000€/mes sin hacer nada nuevo.
¿Qué hago si el negocio dice que ya tiene web?
Le generas la demo igualmente. "Veo que tienes web, pero déjame enseñarte cómo podría quedar con IA." Cuando ven la diferencia entre su web actual y lo que acabas de generar, la conversación cambia. Los negocios con webs anticuadas son en muchos casos mejores prospectos que los que no tienen nada.
¿Cuánto cobro exactamente?
Depende del sector y del negocio. La referencia es: si la web les puede traer 2-3 clientes más al mes y cada cliente vale 100€ o más, cobrar 500-800€ es una decisión fácil para ellos. Nunca pongas el precio antes de entender cuánto vale un cliente para ese negocio.
